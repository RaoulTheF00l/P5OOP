# Persona: Out of Phase

A Persona 5 demake built in Godot 4.x — a pixel art reimagining based on an original fan fiction.

## About

Persona: Out of Phase adapts an original Persona 5 fan fiction into a playable 2D demake. The current goal is a complete, playable version of Kamoshida's Palace arc, with daily life activities, social stat progression, and turn-based combat — all rendered in pixel art.

📖 **Read the fan fiction:** [Persona: Out of Phase on WebNovel](https://www.webnovel.com/book/34622084700862405)

## Features (In Progress)

- **Social Stat System** — Raise Knowledge, Guts, Proficiency, Kindness, and Charm through daily activities
- **Time Management** — Day/night cycle with Morning, Afternoon, Evening, and Night time slots; activities are time-restricted
- **Turn-Based Combat** — Classic P5-style layout with Attack and Skill actions, SP management, and damage formulas
- **Daily Life Hub** — Explore Leblanc with activities like studying, working, crafting, and talking to Sojiro
